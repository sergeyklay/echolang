# EchoLang Frontend

React + TypeScript + Vite frontend for EchoLang translation application.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Environment Variables

Create a `.env` file with:

```
VITE_API_URL=http://localhost:3000
```

The default API URL is `http://localhost:3000` if not specified.
